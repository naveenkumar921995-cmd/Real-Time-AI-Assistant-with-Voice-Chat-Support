# 🤖 AI Voice & Text Assistant

A modern AI-powered Voice & Text Assistant built using Python, Streamlit, and Groq APIs.

The application allows users to interact with AI using both text chat and voice commands directly from the browser.

---

# 🚀 Features

## 💬 Text Chat
- Real-time AI conversations
- Fast response generation
- ChatGPT-style interaction

## 🎤 Voice Assistant
- Browser microphone support
- Voice-to-text transcription
- AI voice interaction

## 🤖 AI Integration
- Powered by Groq LLM APIs
- Multiple AI model support
- High-speed inference

## 🎨 Modern UI
- Glassmorphism design
- Responsive layout
- Mobile-friendly interface
- Premium dark theme

## 📜 Chat Management
- Conversation history
- Download chat history
- Clear chat functionality

## ☁️ Cloud Deployment
- Streamlit Cloud compatible
- Browser-based application
- No local microphone dependency

---

# 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| Python | Backend Development |
| Streamlit | Web Application Framework |
| Groq API | AI Response Generation |
| Whisper API | Speech-to-Text |
| HTML/CSS | Custom UI Design |
| streamlit-mic-recorder | Browser Voice Recording |

# ⚙️ Installation

## 1️⃣ Clone Repository

```bash
git clone https://github.com/your-username/ai-voice-assistant.git
```

---

## 2️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

---

## 3️⃣ Run Application

```bash
streamlit run app.py
```

---

# 🔑 Environment Setup

Create Streamlit Secrets:

